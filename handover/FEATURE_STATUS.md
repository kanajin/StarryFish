# 功能状态

记录时间：2026-10-24，基线 v0.1.12。发布包含功能，并不意味着每一种真实使用组合都已验收。详细行为以链接中的需求文档为准。

| 功能 | 当前状态 | 接手时注意 |
|---|---|---|
| 两种布局、明暗主题、图标标签、双游戏窗、助手面板 | 已在 Windows 产品提供 | 双窗开关、贴边、左侧不足时右扩及正常退出有用户确认；多显示器、DPI 与助手组合未逐项实测 |
| 原生快捷键 | v0.1.12 已发布，有限定范围实战反馈 | 快速角色切换、技能触发、部分菜单与攻击流程已观察；取消攻击、可用 FC 确认、六药水、缩放与双窗组合仍需定向验收 |
| 加密资料导入导出 | v0.1.12 已发布，隔离合成资料和实际组件恢复检查通过 | 真实用户归档与跨机器迁移尚未完成验收；导入跳过登录态，需重新登录 |
| 技能 CD 悬浮条 | 已发布，显示、分组与缩放有用户反馈 | 死亡、换人、封印、不同战斗模式及双窗切换未全面验收；CD 0 不代表技能必定可用 |
| 网络采集 MCP | 已发布，限时与滚动模式均有实现 | 有跨十分钟滚动、淘汰与停止快照的定向观察；完整战报与长期性能仍未验收 |
| ZeroOmega 代理模式、书签、汉化、下载、独立资料 | 已提供 | 第三方组件和游戏页面变化可能影响行为；检查真实代理生效情况，不能仅凭菜单选择判断 |
| 隐藏加载角色和文字 | 已提供开关 | 真实隐藏、恢复及重启记忆仍待定向反馈 |
| GBF 连续后退、Mobage 关闭后的登录接续 | 已有实现和隔离检查 | 真实游戏历史与登录流程仍待受影响用户反馈 |
| 静态资源缓存 | 已提供 | 实际增量加速效果没有测量，不承诺提速比例 |
| WebView 快捷键 SDK | 开发者预览 | 第三方宿主集成尚未验收，原生宿主成功不能直接推定 SDK 成功 |
| Linux | 移植中，未交付完整浏览器 | linux 分支已锁定 CEF 并在 CachyOS 首次编译；隔离 XDG、资料锁、退出、GPU 与 namespace/seccomp 已观察，中文输入/页面缩放用户确认；双布局／主题记忆／基础标签与导航已有合成桌面检查，双窗、完整消息桥及其余功能仍待移植与验收；功能范围见 hosts/linux/PORTING_PLAN.md |

行为与使用边界见 [界面需求](../docs/UI_REQUIREMENTS.md)、[迁移说明](../docs/PROFILE_TRANSFER.md)、[网络采集接口](../docs/NETWORK_CAPTURE.md)、[SDK 说明](../sdk/webview-hotkeys/docs/SDK.md) 和 [发布说明](../RELEASE_NOTES.md)。

后续验证请记录具体版本、构建身份、触发步骤和实际观察。合成数据成功、系统输入接口返回成功或组件连接成功，都不能直接写成真实游戏功能验收。
