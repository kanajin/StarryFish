# 安装、超时与清洁卸载

2026-10-14 新需求，自 v0.1.6 起适用；取代旧版默认保留资料的卸载方式。

- 安装下载的连接/读取等待以及代理扩展回复/PAC请求从15秒改为60秒。下载总预算、大小限制、代理实际读回与未知提交不重放继续保留。15秒代理状态复核是间隔，不是超时。
- 首次安装提供联网获取或本地ZIP两种来源。本地模式要求选择太郎和肉鸽两个ZIP，不调用插件解析/下载接口；原ZIP不修改、移动或删除。
- 本地包经过同样的ZIP格式、展开量、路径/链接、MV3角色、权限、引用资源及运行入口检查，生成同样的接入目录和当前用户完整性记录。记录包hash及本地选择来源，不声称作者签名，不记录选择文件的个人路径。
- 已有安装更新保留已有插件及其资料；该来源选择用于首次安装。已有插件继续采用明确的本地覆盖/重新核对入口。
- 卸载不再提供保留个人数据选项。确认后清除本安装的私有资料、配置、登录态、静态缓存、原程序及可核实的安装/更新/手动重载文件。
- 安装根不递归删除。不可变文件核对安装清单和hash，静态缓存核对命名及自有格式，更新证据核对绑定本安装的所有权记录；无关文件及无法核实的变更文件保留。符号链接、重解析点、硬链接或占用不能通过降低检查来删除。
- 安装器缓存按安装根隔离并记录归属。旧版本登记的确切缓存可接续登记；没有归属证据的旧孤立目录不能被假定属于本次安装而盲删。
- 开始菜单只清除核实指向本安装、且身份未变化的快捷方式。关闭卸载窗口后由独立的系统PowerShell进程在内存中载入已核对的卸载代码，删除所属安装器缓存、自身原文件和收尾记录；不创建常驻程序、批处理或脚本，不修改执行策略。收尾失败会提示，不能假称全部清理完成。
- 当前调用创建的内嵌包临时展开目录按编译清单清理；不处理用户下载的安装器/ZIP，不清除无法绑定本安装的其他临时目录或旧诊断。

检查和源码审查不等于真实安装/卸载验收。用户现有资料与开发证据不会被开发过程删除；删除功能仅由用户在正式卸载向导中确认后执行。
